# 鎖の探索隊 — Chain Expedition

2〜4人(1人でも可)の協力ローグライク。それぞれのスマホからオンラインで一緒に遊べる。
全員が **1本の鎖** でつながったままダンジョンに潜る。武器は鎖だけ。
仲間が踏ん張っている間に走り回って、鎖で敵を切り裂こう。

## 遊び方 (スマホでオンライン)

それぞれ自分のスマホから、同じ部屋に入って遊ぶ。サーバー不要(WebRTC で端末同士が直接つながる)。

1. 公開URL(GitHub Pages)をスマホのブラウザで開き、**横向き** にする
2. 1人が **「部屋を作る」** → 4けたの部屋コードが出る
3. 他の人は **「部屋に入る」** → コードを入力して参加(最大4人)
4. ホストが **「出発！」** をタップ
5. 敵を全滅 → 強化カードを1つ選ぶ(選ぶ人は交代制。タップで選んで、もう一度タップで決定) → 上の出口へ
6. 各層4部屋+ボス、全3層を踏破すればクリア

**操作**: 画面の左半分どこでもスティック、右に **ダッシュ** と **アンカー(長押し)**。

ホストのスマホがゲーム全体を計算し、ゲストには状態を約30回/秒で送る。
ゲームは「ロビーにいる間」だけ参加できる。

### パソコンで遊ぶ場合

「ひとりで練習 / この端末で遊ぶ」を選ぶと、1台で最大4人(キーボード2人+ゲームパッド)。

| | 移動 | ダッシュ | アンカー(長押し) |
|---|---|---|---|
| キーボード左 | WASD | F | G |
| キーボード右 | 矢印 | `.` / テンキー1 | `/` / テンキー2 |
| ゲームパッド | スティック / 十字 | A / RB | B / X / LB / RT |

### 公開のしかた (GitHub Pages)

リポジトリの Settings → Pages → Branch で、このブランチの `/ (root)` を選んで Save。
数分後に `https://raybbb101.github.io/Rou/` で遊べる。
(WebRTC は https が必要なので、ファイルを直接開くのではなく Pages 経由で開く)

テスト用: URL に `?local` を付けると、同じブラウザのタブ同士で通信する。

## コツ

- **アンカー**: その場に踏ん張る。仲間はアンカーを中心に振り回され、加速する
- 鎖は **速く動いているほど** 強く切れる(手元は凶器にならない)
- 敵を鎖で叩いて **穴に落とす** と一撃
- 鎖が柱に引っかかると巻き付く。ボスの周りを回って鎖を巻き付けると **バインド**(拘束+大ダメージ)
- ダウンした仲間のそばに立つと蘇生できる。全員ダウンで全滅
- 1人プレイでは鉄球が相棒(振り回すフレイル)

## 構成

```
index.html
src/engine.js  320x180 のピクセルバッファ描画(色 / 照明 / 発光の3バッファ)、入力、合成音
src/fx.js      オリジナルのピクセルエフェクト(火花・爆散・雷・魔法陣・衝撃波・蘇生の光柱…)
src/game.js    鎖の物理(Verlet ロープ)、プレイヤー、敵、ボス、部屋生成、強化
src/net.js     オンライン協力 (ホストが計算→状態配信、ゲストは補間して描画)
src/render.js  スプライト・UI・メインループ
src/touch.js   スマホのタッチ操作 (スティック・ボタン・画面ボタン)
lib/peerjs.min.js  WebRTC ライブラリ PeerJS 1.5.4 (MIT)
```

エフェクトは pixelfx の考え方(色と光の2バッファ、Bayer ディザ、色ランプの段塗り、
速く出て遅く消える、ヒットストップ)を参考にしつつ、すべて新しく書き起こしたもの。
